# 00.4 Pitch Deck Creation

**Goal:** Visual storytelling that closes the deal.

## 🤖 AI Agent Steps
1.  **Summarize Proposal:** Extract the "Problem," "Solution," and "ROI" from `proposal_v1.md`.
2.  **Slide Outline:** Generate a 5-7 slide markdown structure.
    -   *Slide 1:* The "Villain" (Current Pain).
    -   *Slide 2:* The "Guide" (Your Agency).
    -   *Slide 3:* The "Plan" (The Roadmap).
    -   *Slide 4:* The "Transformation" (Concept Art).
    -   *Slide 5:* The "Ask" (Timeline & Price).

## 👤 Human Steps
1.  **Visual Polish:** Use a tool or the Agento Bento "Lens" to visualize the roadmap slide.
2.  **No Text Walls:** Keep slides fewer than 20 words each. Speak to the slides; don't read them.

## 📄 File Output
-   `01_Strategy/pitch_deck.md` (or `.pptx` if using a generator).
