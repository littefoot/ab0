# 02.1 Brand Identity Setup

**Goal:** Establish the visual language.

## 🤖 AI Agent Steps
1.  **Color Extraction:** If client has a site, extract Hex codes. If not, suggest palettes based on "Vibe" (e.g., "Corporate and Trustworthy" = Navy Blue).
2.  **Logo Placeholders:** Create `02_Assets/Brand/Logos` folder.

## 👤 Human Steps
1.  **Upload Assets:** Drop existing `logo.svg`, `fonts`, and `styleguide.pdf` into `02_Assets/Brand`.
2.  **Update Config:** Update `system.config.json` with primary colors for the UI customization.

## 📄 File Output
-   `02_Assets/brand_guidelines.md`
