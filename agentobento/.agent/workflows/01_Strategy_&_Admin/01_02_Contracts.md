# 01.2 Contract and Scope

**Goal:** Define boundaries to prevent scope creep.

## 🤖 AI Agent Steps
1.  **Scope Definition:** Extract the "Deliverables" list from `proposal_v1.md`.
2.  **Draft Contract:** Fill a standard MSA (Master Services Agreement) template with:
    -   Client Name & Address.
    -   Project Total & Payment Schedule (e.g., 50% upfront, 50% on launch).
    -   "Definition of Done" for each deliverable.

## 👤 Human Steps
1.  **Legal Check:** Brief review for any red flags.
2.  **Send for E-Sign:** Use Hellosign/DocuSign.

## 📄 File Output
-   `01_Strategy/contracts/MSA_[Client_Name].md`
