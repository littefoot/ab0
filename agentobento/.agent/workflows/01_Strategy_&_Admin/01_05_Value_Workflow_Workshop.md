# 01.05 Value Workflow Workshop

**Goal:** Visualizing how the business actually makes money and delivers happiness.

## 1. The Growth Workflow (Acquisition)
*How customers happen.*
**Goal:** Awareness -> Conversion.

### 🤖 AI Agent Steps
1.  **Map the Steps:**
    -   **Traffic:** (e.g., SEO, Ads, Referrals).
    -   **Lead Magnet:** (e.g., The PDF, The Webinar).
    -   **Nurture:** (e.g., Email Sequence).
    -   **Conversion Event:** (e.g., Discovery Call, Checkout).

## 2. The Fulfillment Workflow (Delivery)
*How value is delivered.*
**Goal:** Order -> Referral.

### 🤖 AI Agent Steps
1.  **Map the Steps:**
    -   **Onboarding:** (e.g., Kickoff form, Welcome email).
    -   **Value Delivery:** (e.g., The Service, Shipping).
    -   **Support:** (e.g., Helpdesk).
    -   **Ascension:** (e.g., Upsell, Testimonial Request).

## 👤 Human Steps
1.  **Whiteboard Session:** Draw these two flows.
2.  **Identify "Breaks":** Where are leads falling off? Where are customers getting angry?
3.  **Digitize:** Save the diagram to `01_Strategy_&_Admin/value_workflows.png`.
