# 01.04 The Clarity Compass

**Goal:** Empower the team to make decisions without asking the Founder.

## The 4 Filters
Before making any decision, run it through these 4 filters in order. If it fails one, stop.

### 1. The Company Case (Goals)
*   **Question:** Does this move us closer to our 3-Year Vision or current Roadmap goals?
*   *If No:* Reject.
*   *If Yes:* Proceed.

### 2. The Customer Case (Purpose)
*   **Question:** Does this solve a real problem for our Avatar? Does it add value to their life?
*   *If No:* Reject.
*   *If Yes:* Proceed.

### 3. The Culture Case (Values)
*   **Question:** Is this consistent with our Core Values? Would we be proud to tell the team?
*   *If No:* Reject.
*   *If Yes:* Proceed.

### 4. The Competitive Case (Strategy)
*   **Question:** Does this leverage our unique strengths? Is it something only we can do well?
*   *If No:* Outsourcing candidate?
*   *If Yes:* Do it.

## 🤖 AI Agent Steps
1.  **Decision Bot:** In Slack/Discord, when a team member asks "Should we do X?", the Agent replies with these 4 questions.
