# Marketing: Create Lead Magnet

**Goal:** High-value freebie to capture emails.

## 🤖 AI Agent Steps
1.  **Concepting:** Suggest 3 titles based on the "Avatar" pain points.
    -   e.g., "The 5-Step Checklist to [Result]" or "The Anti-[Problem] Guide".
2.  **Drafting:** Generate the content skeleton (Introduction, 3 Core Steps, CTA).
3.  **Design Brief:** Create a prompt for the designer (or AI image generator) for the cover.

## 👤 Human Steps
1.  **Polish:** Refine the copy. Ensure the "Aha!" moment is real.
2.  **Production:** Layout in Canva/Figma or use a simple Markdown-to-PDF tool.
3.  **Save:** `02_Assets/Marketing/02_Lead_Magnets`

## 📄 Deliverable
-   PDF or Access Link.
