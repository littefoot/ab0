# Universal Business Operating System (BOS) Index

This document serves as the **Master Map** for the Agento Bento Workflow Library. It is designed to be a comprehensive operating system for *any* small business, from local shops to digital agencies.

## 🗺️ How to Use This Library
**Select your Archetype below to see which modules to install.**

### 🏛️ The Agency Archetype
*Focus: B2B Sales, Client Deliverables.*
-   **Installs:** 00 (Full), 01 (Strategy), 02 (Marketing), 03 (Project Init).

### 🏪 The Local Shop Archetype
*Focus: Operations, Local Traffic.*
-   **Installs:** 01 (Admin), 02 (Local SEO), 03 (SOPs), 04 (Hiring).

### 🎨 The Creator Archetype
*Focus: Audience, Content.*
-   **Installs:** 01 (Brand), 02 (Content), 05 (Performance).
