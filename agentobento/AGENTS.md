2.  **Data Sovereignty**: The user owns the "Source of Truth" in local, human-readable formats (Markdown/JSON).

4.  **The 3-Layer Architecture**:
    *   **The Soul**: The files/folders (User Interface).
    *   **The Brain**: You (The Agent/Antigravity).
    *   **The Pulse**: n8n (Background Automation).
