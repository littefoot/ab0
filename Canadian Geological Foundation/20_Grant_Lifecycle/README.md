# 20_Grant_Lifecycle (Pipeline)

**Purpose:** Managing the core product: **The Grants**.

## Pipeline Stages
1.  **Intake:** Applications received (Google Forms / Typeform -> JSON).
2.  **Review:** Committee evaluation and scoring.
3.  **Award:** Notification and Agreement signing.
4.  **Disbursement:** Payment tracking.
5.  **Reporting:** Post-project impact reports.

*Note: Use `applications.json` or markdown files here to track active grants.*
